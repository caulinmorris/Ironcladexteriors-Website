RECOMMENDED DEPLOYMENT (NETLIFY + GITHUB)
1. Create a new GitHub repository.
2. Upload every file/folder from this package to the repository root.
3. In Netlify, choose Add new site > Import an existing project and connect that GitHub repository.
4. Build command: leave blank. Publish directory: .
5. Deploy the site.
6. In Netlify, enable Identity. Set registration to Invite only.
7. Enable Git Gateway under Identity / Services.
8. Invite your email as an Identity user.
9. Visit https://YOUR-SITE.netlify.app/admin/ and sign in.
10. In the editor, change website content and upload real project photos. Publishing creates a Git commit and Netlify republishes the site.
11. In Netlify Domain management, add ironcladexteriors.com and follow the DNS instructions shown for your registrar.

FORMS
The Free Estimate and Launch Home forms are built with Netlify Forms. After deployment, verify Forms in the Netlify dashboard and submit one test entry from each form.

IMPORTANT PHOTO NOTE
The website intentionally ships with photo placeholders instead of stock photography. Use /admin/ to upload your real installs, crew/team photo, doors, siding, black windows, brick homes, before/afters, and specialty windows.
